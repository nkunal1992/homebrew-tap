# homebrew-tap

Homebrew tap for [Trakisilo](https://nkunal1992.github.io/Trakisilo-site/) — free, offline-first kanban + clipboard + time tracking.

```bash
brew install --cask nkunal1992/tap/trakisilo
```

**First launch:** the build is unsigned — approve once via
System Settings → Privacy & Security → **Open Anyway**. Repeat after updates.

**Update:** `brew upgrade --cask trakisilo` · **Uninstall:** `brew uninstall --zap --cask trakisilo`
